第一章：多媒体技术概述

多媒体的定义和特征

多媒体技术的定义：

利用计算机技术对多种信息进行综合处理、建立逻辑关系，集成为一个具有交互性的系统。

五大特征：

  1. 多维化：媒体信息的多样化。
  2. 集成性：不同媒体信息和媒体设备有机结合。
  3. 交互性：人与计算机之间能够进行交互，是多媒体技术最关键的特征。
  4. 数字化：媒体信息以数字形式存在。
  5. 实时性：声音、动态图像等信息随时间变化。

媒体的五种类型（CCITT）

感觉媒体： 能直接作用于人的感官，使人产生感觉的媒体（语言，图像等）。

表示媒体：为了加工、处理和传输感觉媒体而人为构造出来的一种媒体，即各种编码（文本编码，语音编码等。

显示媒体：用于感觉媒体与电信号之间相互转换的媒体。包含输入显示媒体（键盘，鼠标等）；和输出显示媒体（显示器，音响等）。

存储媒体： 用于存储表示媒体，以便本机或其他终端远程使用（硬盘，U盘等）。

传输媒体：用于将表示媒体从一处传送到另一处的物理实体（电话线，电缆等等）。

第二章：多媒体数据的采集

MPC 多媒体计算机系统

MPC（Multimedia Personal Computer），即多媒体个人计算机。

组成：

硬件系统：计算机硬件、I/O 控制卡及接口、外围设备。

软件系统：操作系统、驱动软件、应用软件。

声卡

音频卡（Audio Card）又称声音卡，是处理音频信号的 PC 插卡。

主要处理三类音频媒体：

  1. 数字化声音（Wave）。
  2. 合成音乐（MIDI）。
  3. CD 音频。

主要功能：

  • 音频录制与播放。
  • 音频编辑与合成。
  • MIDI 接口。
  • CD-ROM 接口。
  • 游戏接口。

现在音频功能大多集成在主板上，但其本质仍属于通过接口设备接入计算机系统的功能。

显卡

显卡负责接收计算机需要显示的图形数据，进行图形处理，再输出显示信号到显示器。

常见组成及作用：

组成 作用
GPU 进行图形运算和处理
显存 暂存图形数据
显示接口 连接显示器，输出图像信号

数码相机的工作原理

两个重要部件：

CCD（电荷耦合器件）

  • 基本光敏单元：像素。
  • 作用：将可见光转换成电信号。

译码器

- 作用：将电信号转换成数字信息。

流程：镜头接收影像 → CCD 将可见光转换为电信号 → 译码器转换为数字信息 → 存储介质（比如软盘）保存 → 数据接口传输。

音频数字化的三个步骤

第一步：采样

将时间上连续变化的模拟信号转换为时间上离散的信号，即每隔一定时间取一个样本。

采样周期：相邻两次采样之间的时间间隔，记为 T。

采样频率：每秒采样次数，记为 f。

第二步：量化

将采样得到的连续幅度值划分到有限个离散电平中，并赋予相应的量化值。

如果使用 n 位二进制数表示量化电平：量化级数=2^n

量化位数越多，量化越精细，量化误差通常越小。

第三步：编码

用二进制数码表示各个量化电平的过程。

保持电路

保持电路：在两次采样之间，暂时保持上一次采样得到的幅度值不变，为后续 A/D 转换提供稳定的信号。

工作流程分为两阶段：

采样：采样脉冲 S(t) 到来，场效应管 VT 导通，输入信号向电容 C 充电，输出电压跟随输入电压。

保持：采样脉冲结束，场效应管 VT 截止，电容 C 保持之前的充电电压，输出电压暂时不变，直到下一次采样。

元件 作用
场效应管 VT 采样门，控制采样
电容 C 保持电容，保持采样电压
运算放大器 跟随器，起缓冲隔离作用

奈奎斯特抽样定理

假设原始声音中最高频率是 20kHz,如果采样频率只有 10kHz，那么采样得到的数据可能无法准确还原原始声音。所以，采样频率必须满足一定条件。

定理内容：要想抽样后能够不失真地还原出原信号，抽样频率必须大于信号频谱最高频率的两倍。

其中：

  • fₛ：采样频率。
  • fₘₐₓ：信号的最高频率。

A/D 转换器

A/D转换，就是将模拟信号转换为数字信号。

直接转换法

原理：通过一套基准电压与取样保持电压进行比较，直接将模拟量转换成数字量。

特点：

  • 工作速度高。
  • 转换精度容易保证。
  • 调准比较方便。

直接 A/D 转换器包括：

  • 计数型
  • 逐次比较型
  • 并行比较型

间接转换法

原理：将取样后的模拟信号先转换成中间变量时间 t或频率 f，然后再将时间或频率转换成数字量。

特点：

  • 工作速度较低。
  • 转换精度可以做得较高。
  • 抗干扰性强。

A/D 转换器的三个技术指标

分辨率

分辨率表示 ADC 对输入模拟电压微小变化的分辨能力，通常用输出二进制数字量的 位数 来表示（如 8 位、12 位、16 位）。

位数越高，分辨率越高，能区分的电压差越小，量化越精细。

若满量程输入电压为 VFS，则分辨率对应的最小可分辨电压为：

ΔV = VFS / 2n

例如，满量程 5V 的 8 位 ADC，最小能分辨约 5 / 256 ≈ 19.53mV 的电压变化。

转换时间

从接到转换启动信号开始，到输出端获得稳定数字信号所经过的时间。

类型 转换时间 速度
双积分型 几百毫秒 最慢
逐次逼近式 几十微秒 较快
并行比较型 几十纳秒 最快

转换误差

A/D 转换器实际输出与理论输出之间的差别。

第三章 ：数据压缩理论

数据压缩的基本原理

核心原理：消除数据中的冗余。

基本思想：建立以少代多或以局部代全体的数据变换关系，从而以最少的数码表示信号。

数据冗余的四种类型

冗余类型 关键词 典型例子
空间冗余 相邻区域 相邻像素颜色相似
时间冗余 相邻帧 连续视频画面相似
熵冗余 概率分布 高频符号使用短编码
其他冗余 结构、知识 纹理、人脸

数据压缩的评价指标

数据压缩的四个评价指标

指标 主要衡量内容
压缩比 输出数据与输入数据之比
压缩质量 压缩后接近原始数据的程度
压缩速度 压缩和解压缩所需时间
标准化 是否遵循统一标准

无损压缩与有损压缩

无损压缩：压缩后的数据经过解压缩，能够完全恢复原始数据，不会丢失信息。（哈夫曼编码，算数编码，行程编码）

有损压缩：压缩过程中允许丢失部分信息，解压后不能完全恢复原始数据。(FFT：快速傅里叶变换 ; DCT：离散余弦变换; DWT：离散小波变换)

压缩模型的构成原理

压缩模型分为编码过程和解码过程

  1. 编码过程

原始数据经过编码器处理，转换为适合存储和传输的编码数据。

其中有两个部分：

  • 信源编码器：完成大部分压缩任务。
  • 信道编码器：主要解决传输可靠性问题，降低调制、解调过程中的误码率。

熵编码：概率大的信息使用短码字，概率小的信息使用长码字。

  1. 解码过程

将接收到的编码数据恢复为原始内容，完成码元恢复与信号合成。

压缩和解压缩的对称性：

  • 对称：压缩和解压缩的实时性要求相近。
  • 非对称：例如压缩非实时，解压实时。

哈夫曼编码

哈夫曼编码是一种无失真编码的优选算法：出现概率大的符号使用短码字，出现概率小的符号使用长码字。

算法步骤：

  1. 建立概率表：统计信源符号出现频率，计算每个符号的概率，并按概率递减排列。
  2. 建立哈夫曼树：每次选择两个最小概率项，将它们相加形成新的复合项，重复操作直到形成根节点。
  3. 生成编码：从根节点遍历到叶节点，根据路径上的 0 和 1 得到每个符号的编码，并计算平均码长。

例如：

符号 概率 编码 码长
A 0.4 0 1
B 0.3 10 2
C 0.2 110 3
D 0.1 111 3

平均码长：L = Σ P(Xi) × Li

编码效率：η = H(X) / L × 100%

  • η：编码效率
  • H(X)：信源信息熵（最小平均码长）
  • L：实际平均码长

第四章：声音编码压缩技术

模拟声音与数字声音

什么是模拟声音？

现实中的声音本质上是一种连续变化的物理信号，例如说话时，声音的振幅会随着时间不断变化。

模拟信号具有两个特点：

  • 时间连续。
  • 幅度连续。

但是计算机无法直接按照模拟信号的形式处理和存储声音，因此需要将其转换成数字信号。

什么是数字音频？

数字音频就是将连续的模拟声音信号转换成离散的数字信号

通过之前学的：采样，量化，编码

PCM 脉冲编码调制

定义： PCM 是将模拟信号转换为数字信号的一种调制方式。

它属于波形编码，目标是使重构语音信号的波形尽量接近原始信号波形。

步骤：采样，量化，编码

PCM 的两种量化方式：

1.均匀量化 ：采用相等的间隔度量采样得到的电平。

2.非均匀量化 ： 根据输入信号幅度大小，使用不同的量化间隔。

规则：

  • 大的输入信号采用大的量化间隔。
  • 小的输入信号采用小的量化间隔。

PCM计算题

数据量(KB) = 采样频率(KHz) × 采样位数(bit) × 声道数 × 时间(s) / 8

μ律和 A律压扩

压扩算法 主要应用地区 参数
μ律（Mu-law） 美国、日本 μ = 255
A律（A-law） 中国、欧洲 A = 87.56

G.711 ：是电话质量音频压缩标准（采集频率8khz；量化位数8bit；数据速率64kb/s）

APCM 自适应脉冲编码调制

定义：根据输入信号幅度大小，动态改变量化阶大小的一种波形编码技术。

输入信号幅度 量化阶
小幅度信号 小量化阶
大幅度信号 大量化阶

瞬时自适应与非瞬时自适应

瞬时自适应：量化阶的大小每隔几个样本就改变。

非瞬时自适应：量化阶的大小在较长时间才发生变化。

前向自适应与后向自适应

APCM 改变量化阶大小的方法有两种：

前向自适应：

根据未量化样本值的均方根值，估算输入信号的电平，以此确定量化阶的大小。然后将估算得到的电平编码，作为边信息传送到接收端。

后向自适应：

从量化器刚输出的过去样本中提取量化阶信息。

DM 增量调制

这是 PCM 的一种变形，也是一种预测编码技术。

核心思想：不直接传输采样信号的具体幅度，而是判断实际采样信号与预测信号之间的差值是正还是负：

  • 如果实际采样信号与预测信号之差为正，用 1 表示。
  • 如果实际采样信号与预测信号之差为负，用 0 表示。

DM 的两个问题

① 斜率过载 ：增量调制器的输出不能跟踪输入信号的快速变化。

假设输入信号突然快速上升，但 DM 每次只能按照固定步长向上调整。

② 粒状噪声 ：在输入信号缓慢变化的部分，输出交替出现 0 和 1，形成的噪声。

比如输入信号已经比较平稳，但 DM 仍然不断调整输出。

ADPCM 自适应差分脉冲编码调制

定义：综合了 APCM 的自适应特性和 DPCM 系统的差分特性，是一种性能优越的波形编码。

  • APCM：根据输入信号幅度动态改变量化阶。

子带编码（SBC）

它和前面学的 PCM、DPCM 不太一样。它不是直接对整个声音信号进行编码，而是先把声音分成不同频率的部分，再分别编码。

定义：把输入信号的频带分成若干个连续的子带，对每个子带采用单独的编码方案。

分三步：

  1. 分频：将输入声音分成若干连续子带。
  2. 编码：每个子带单独编码。
  3. 解码：分别译码，再组合恢复原始音频。
子带 量化阶 编码位数
低频 小量化阶 高位数
高频 相对较少位数 少位数

优点：各子带可以根据能量和人的听觉感觉分别处理。

BPF带波过滤器：允许特定频率范围内的信号通过，过滤掉其他频率范围的信号（例如把声音分成低频和高频）

G.722 将子带编码与 ADPCM 结合。

核心过程：先将输入声音分成两个子带，再分别使用 ADPCM 编码。

线性预测编码（LPC）

基本思想：声道是惰性腔体，不可能发生突变，因而话音信号具有短时间内的相关性。通过
分析话音波形来产生声道激励和转移函数的参数，对声音波形的编码就转化为对这些参数的
编码，这就使声音的数据量大大减少。

第五章：数字图像与视频技术

颜色空间

颜色空间就是一套描述颜色的规则。

RGB

RGB 分别代表：Red，红色；Green，绿色；Blue，蓝色。

任何颜色都可以由红、绿、蓝三种颜色值组合确定。

RGB 构成一个三维矢量空间。每种颜色都可以用一个三维坐标表示：(R,G,B)

RGB 用于显示器，属于加色法。

HSI

字母 英文 中文
H Hue 色调
S Saturation 饱和度
I Intensity 亮度

HSI 更符合人对颜色的认识

CMY

  • C：Cyan，青色。
  • M：Magenta，品红。
  • Y：Yellow，黄色。

主要应用：彩色打印、彩色印刷。

它属于减色法。

C = 255-R， M=255 - G，Y = 255 - B

另外，CMYK 是在 CMY 基础上增加黑色 K。

YUV、YIQ、YCbCr

为彩⾊电视开发的，Y，U，V可以通过RGB的线性组合求出。
Y是亮度，人眼对亮度最敏感

特点：将亮度和色度分离

因为传统黑白电视只能显示亮度信息，而彩色电视还需要传输颜色信息。

数字图像属性

图像分辨率

定义：每英寸长度上的像素点数量

概念 含义
图像分辨率 每英寸长度上的像素点数量
显示器分辨率 屏幕横向与纵向显示的点数

图像深度

表示每个像素使用多少个二进制位来表示

比如：24位图像

RGB 三个颜色分量各占 8bit。

颜色数量：

32位图像在此基础上加一个8位的Alpha 属性（Alpha 属性可以用于在图像上叠加文字等内容）

真彩色与伪彩色

真彩色：颜色由 RGB 三个分量直接确定

伪彩色：像素的颜色不是由 RGB 直接确定，而是根据像素值到彩色查找表中查找。

位图与矢量图

位图：由一个个像素点组成的图像(PNG,BMP,JPEG,GIF,TIFF)

特点：

  1. 由像素组成。
  2. 图像放大后可能出现马赛克。
  3. 图像质量与分辨率有关。
  4. 适合表示照片、真实场景等复杂图像。

BMP:不压缩图像数据，因此文件较大

GIF：强压缩的图像，交错显示，将多个图像保存为⽂件，从⽽实现动画

TIFF：⾼清晰度，论⽂中使⽤

PNG：⽆损压缩

JPEG：使⽤压缩算法，压缩率⾮常⾼。

矢量图：使用数学公式描述图像中的点、线、曲线和形状（SVG)

特点：

  1. 使用数学描述图形。
  2. 放大或缩小通常不会失真。
  3. 文件大小通常与图形复杂程度有关。
  4. 适合图标、Logo、工程图等。

JPEG 静态图像压缩算法

JPEG是一种用于连续色调、多级灰度静态图像的压缩编码标准。

第一步：颜色空间转换与子采样

RGB 转换为 YCbCr：分离亮度与色度，便于后续压缩。

第二步：DCT 离散余弦变换

JPEG 使用正向离散余弦变换 FDCT

DCT作用：使图像能量集中在少数几个系数上。

对每个图像分量，把整个分量图像分成 8×8 的图像块，再分别进行 DCT。

DCT两种累进：

  • 频谱选择：按频率分组。
  • 按位逼近：按高低位分组。

第三步：量化

量化就是：对 DCT 变换后的频率系数进行处理，减小非零系数的幅度，增加零值系数的数量。

DCT 后会产生 64 个系数，其中很多高频系数比较小；我们可以通过量化，把一些较小的系数变成 0，这样后面编码时就能减少数据量。

第四步：Z 字形扫描

经过 DCT 和量化后，我们得到一个 8×8 的系数矩阵。

这个矩阵有一个特点：

  • 左上角主要是低频系数。
  • 右下角主要是高频系数。
  • 量化后，右下角的高频系数通常有大量的 0。

所以，我们希望把矩阵转换成一维数据，并且让连续的 0 尽可能集中。

通过Z字扫描增加连续的“0”系数的个数

第五步：DC 系数编码

一个 8×8 图像块经过 DCT 后：

  • 左上角的 F(0,0) 是 DC 系数。
  • 其余 63 个是 AC 系数。

DC 系数反映图像块的整体亮度。

相邻图像块的 DC 系数通常变化不大。

因此 JPEG 不直接编码每个 DC 系数，而是编码相邻图像块之间的差值（DPCM）

第六步：AC 系数编码

使用行程长度编码RLE对交流系数AC进行编码

AC 系数有一个特点：包含许多连续的 0 系数。

第七步：熵编码

什么是熵编码？

熵编码根据符号出现的概率分配不同长度的编码。

  • 出现频率高的符号：使用较短编码。
  • 出现频率低的符号：使用较长编码。

JPEG2000

JPEG存在方块效应等一些问题

JPEG 使用 DCT，JPEG2000 使用小波变换。

JPEG2000 的四大特点

1. 高压缩率

与 JPEG 相比JPEG2000 的压缩率提高约 30%。

2. 无损压缩

普通 JPEG 主要采用有损压缩。

JPEG2000 将无损编码方法集成到标准中。

3. 渐进传输

渐进传输就是图像不是一次性完整传输，而是逐步传输。

接收方：

  1. 先看到粗略图像。
  2. 随着数据不断接收，图像逐渐清晰。
  3. 最后获得完整图像。

4. 感兴趣区域压缩

假设一张图片：

  • 人脸是重要区域。
  • 背景是不太重要的区域。

我们希望人脸保持较高画质，背景可以适当降低画质。

JPEG2000 就允许用户指定感兴趣区域，并对不同区域设置不同的压缩质量。

视频冗余

视频的两种冗余：

1.空间冗余 ：单帧图像内部像素之间存在相关性。

通过DCT帧内压缩解决

2.时间冗余：视频相邻帧之间存在大量相似内容。

通过帧间压缩解决

I 帧、P 帧、B 帧

I 帧：帧内编码

I 帧不需要参考其他帧，完全依靠自身图像信息进行编码，相当于一张独立的 JPEG 图像，独立解码

P 帧：预测帧

P 帧不需要完整保存整张图像，而是参考前面已经编码的 I 帧或者 P 帧

假设前一帧中，一个人的脸在画面左边。

当前帧中，脸移动到了右边。

P 帧可以：

  1. 在前一帧中寻找对应的人脸区域。
  2. 计算它移动的方向和距离。
  3. 利用参考帧预测当前图像。
  4. 编码预测误差和运动矢量。

这样就不需要完整传输当前帧。

B 帧：双向预测帧

B 帧可以同时参考前面的图像和后面的图像。

例如：

  • 前一帧：人物还没有移动到中间。
  • 后一帧：人物已经移动到中间。
  • 当前 B 帧：利用前后两帧共同预测人物的位置。

这样通常能获得更高的压缩效率。

I帧压缩比7:1，P帧压缩比20:1，B帧压缩比50:1。平均压缩比约为27:1。

运动补偿与运动矢量

运动补偿：通过参考帧的局部图像来预测、补偿当前的局部图像，从而减少视频帧序列的时间冗余。

视频帧间压缩采用 16×16 宏块进行运动补偿。

运动补偿以宏块为预测单元，而不是直接对整张图像进行一次预测。

运动矢量是描述当前宏块相对于参考宏块移动情况的二维矢量。

它包含两个信息：

  1. 运动方向
  2. 运动幅度（移动距离）

比如位移为：
$$
MV=(5,\ 4)
$$
表示向右移动 5 个像素，向下移动 4 个像素。

MSE 和 MAD

刚才讲到运动补偿需要在参考帧中寻找最佳匹配宏块；参考帧中可能有很多相似的宏块，究竟选择哪一个？

两种最佳匹配准则：

一、均方误差 MSE

核心思想：计算两个宏块对应像素差值的平方，再求平均。

$$
\boxed{
MSE=\frac{1}{N}\sum_{i=1}^{N}(A_i-B_i)^2
}
$$

符号 含义
N 宏块中的像素数量
A_i 当前宏块第 i 个像素值
B_i 候选参考宏块对应位置的像素值
Σ 对所有像素求和

如果使用 16×16 宏块：

$$
N=16\times16=256
$$

计算例题（用2✖2的宏块模拟）：

当前宏块：

​ 31 39

第一步：对应像素相减。

第三步：求平均。

$$
MAD_A = \frac{1+1+1+1}{4}=1
$$

二、平均绝对误差 MAD

核心思想：计算两个宏块对应像素差值的绝对值，再求平均。

公式
$$
MAD = \frac{1}{N}\sum_{i=1}^{N}|A_i-B_i|
$$

第六章：多媒体通信与网络

多媒体通信的服务质量QoS

相比普通通讯，多媒体通讯更关注实时性，低延迟，音视频同步等等

QoS 就是衡量网络能不能满足多媒体应用需求的一套标准；有五个重要参数：

参数 含义 主要解决的问题
吞吐量 网络实际有效传输能力 传输量够不够
延时 数据从发送端到接收端所需时间 是否卡顿、响应是否及时
延时抖动 数据包延时的变化量 播放是否稳定
差错率 数据传输发生错误的比例 数据是否可靠
服务可用性 网络能够正常提供服务的时间比例 网络是否经常中断

延时有四种：

延时 产生原因 主要影响因素
传播延时 信号在信道中传播 传输距离
发送延时 将分组发送到链路上 分组长度、传输速率
排队延时 在路由器队列中等待 网络拥塞
处理延时 路由器分析处理分组 处理能力

延时抖动解决方法：

在接收端设置一个缓冲区，先缓存到达的数据包，再按照稳定的速率播放。

可靠性需求ARQ 和 FEC

ARQ：自动重传请求；发现数据传输错误后，请求发送端重新发送数据。

ARQ 在差错率高的情况下不适用，因为重传导致的时间不可控

FEC：前向纠错；发送端提前增加冗余信息，接收端利用这些冗余信息检测并纠正错误，不需要请求发送端重新传输。

（CRC）用于差错检测，但是不能纠错

对比 ARQ FEC
中文 自动重传请求 前向纠错
核心思想 出错后重新发送 提前增加冗余信息
是否需要重传 需要 通常不需要
延迟 可能较大且不可控 通常较低
带宽开销 重传增加开销 冗余数据增加开销
实时通信 不太适合高差错环境 比较适合

多媒体同步需求

对比 流间同步 流内同步
同步对象 不同媒体之间 单个媒体流内部
主要目的 保证媒体之间协调 保证媒体内部时间关系
典型例子 音视频同步 音频包连续播放
主要问题 声音和画面不同步 声音断断续续
PPT定义 一种端到端的服务 按延时和抖动约束传送媒体分组流

服务可用性

定义：给定时间范围内，网络可提供服务的时间与给定时间之比，也称平均无故障率。

计算公式：

服务可用性 = 正常运行时间 / 总时间 × 100%

QoS 服务的分类

确定型 QoS： 网络提供“硬”的 QoS 保证，全程保证。通过预留带宽的方式保证。

统计型 QoS： 在数据传输过程中，网络提供“软”的 QoS 保证，统计保证。

尽力型 QoS： 没有 QoS 保证，如果负载增加的话，通信质量会大幅下降。

QoS 保证机制

RSVP = 为数据流申请和预留网络资源

流程：

第一步：发送 PATH 消息（发送端 → 接收端）

第二步：接收端收到 PATH（了解数据传输路径）

第三步：发送 RESV 消息（接收端 → 发送端，沿 PATH 相反方向）

第四步：沿途路由器检查资源（检查是否能够满足带宽预留请求）

第五步：发送端收到资源预留消息

DiffServ区分服务

核心思想：在网络边界对数据流进行分类，网络内部根据不同类别提供不同的转发服务。

DiffServ = 分类 + 优先级 + 差异化转发。

多媒体网络的应用类型

类型 典型应用 延时要求
现场交互 网络电话、视频会议 小于150ms最好，150～250ms可接受
交互应用 声音点播、影视点播 1～5秒可以接受
非交互应用 声音广播、电视广播

多媒体通信协议

主要是RTP、RTCP、RTSP 三大多媒体协议

RTP：实时传输协议

RTP 为实时应用提供端到端运输，但不提供任何服务质量保证。

主要应用：

  • 网络电话。
  • 视频会议。
  • 流媒体通信。
  • 网络电视。

RTP 本身不负责压缩音视频，而是在压缩编码后的数据上增加一些附加信息。

流程：音视频数据经过压缩编码，RTP 封装增加序号、时间戳等信息，UDP 封装，IP 网络传输

RTCP：实时传输控制协议

RTCP 是与 RTP 配合使用的协议，它主要为应用程序提供会话质量或者广播性能的信息。

RTCP 负责统计接收端信息，包含信息包的数目、丢失率和抖动等。

RTCP 只负责统计，后续操作取决于应用开发人员。

RTSP：实时流播协议

RTSP以客户端/服务器⽅式⼯作，是⼀个多媒体播放控制协议。
它使得⽤户在播放视频时可以进⾏控制，⽐如暂停，前进，后退等
RTSP在RTP和RCTP之上，使⽤TCP完成数据传输
RTSP 负责控制 RTP 会话，本身并不传输音视频数据。

网络上的交换技术

网络交换技术主要分为：电路交换、报文交换、分组交换。

一、电路交换

定义： 通信前先建立一条专用通路，数据以连续比特流的形式从源点传输到终点。

工作过程： 建立连接 → 传输数据 → 释放连接。

数据以⽐特流的形式直达终点

二、报文交换

定义： 以完整报文为单位，采用存储转发方式进行传输。

特点：

报文包含完整数据，长度不固定。

中间节点必须接收完整报文后才能转发。

不需要提前建立专用通路。

存储和排队延时可能较大，不适合严格的实时通信。

三、分组交换

定义： 将较长的消息拆分为多个较小的数据包（分组），每个分组携带必要的控制信息，通过网络逐跳

存储转发。

工作过程：

原始消息 → 拆分分组 → 存储转发 → 接收端恢复数据

特点：

各分组可以独立传输，可能经过不同路径。

多个用户共享网络带宽，资源利用率较高。

网络拥塞时可能出现延时、抖动和丢包。

典型应用： 互联网、视频通信、文件传输。

第七章：超媒体与 Web 系统

超媒体与 Web 系统

信息的组织方式应该和思维方式很相似。

信息是普遍联系的，在逻辑上是多维立体关联的，其中包括时间关联和空间关联。

人的认知是收敛递归的。

多媒体、网络迫切需要一种技术，能高效管理信息，并建立信息管理——超文本与超媒体技术。

超文本

超文本是一种信息管理技术，它以节点作为基本单位，节点实际是一个信息块。在信息组织方面，则是用链把节点构成网状结构，即非线性结构。

超文本还包含 信息之间的逻辑关系，使用节点 + 链 + 非线性网状结构

超媒体

超媒体 = 多媒体 + 超文本

超文本原本主要组织文字信息，超媒体则可以组织多种媒体信息。

超媒体系统的组成——节点和链

节点：是存储信息的基本单元，又称信息块，每个节点包含一个特定主题的信息。

链：链表示不同节点之间信息的联系，由一个节点指向其他节点。
