两数之和

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target 的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

https://leetcode.cn/problems/two-sum/description/

HashMap

  1. 遍历数组，用 HashMap：key = 数组值，value = 下标
  2. 对当前元素 nums[i]，需要找 c = target - nums[i]
  3. 如果 c在 map 里：找到答案，返回 [map.get(c), i]
  4. 不在 map：把 nums[i],i 放入 map，继续遍历

三数之和

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

https://leetcode.cn/problems/3sum/

排序+双指针

  1. 数组排序 O (nlogn)

  2. 固定第一个数 nums[i]，i 去重（相同 i 跳过，避免重复答案）

  3. j = i+1（左指针），k = n-1（右指针），

    • sum = nums[i]+nums[j]+nums[k]
    • sum < 0：总和太小，j++
    • sum > 0：总和太大，k--
    • sum == 0：记录答案；j、k 去重；j++，k–

  4. 外层循环 i 从 0~n-1
